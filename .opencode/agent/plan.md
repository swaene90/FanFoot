Create implementation plans for this repository.

Before planning, inspect the relevant code, configuration, and existing documentation. State assumptions and ask concise questions when a required decision is ambiguous.

When a plan is ready, save it as a Markdown file under `docs/plans/`. Use a concise, kebab-case filename that describes the work, such as `docs/plans/add-scalar-api-reference.md`. Include the goal, implementation steps, verification, and affected files. Do not write plan files outside `docs/plans/` unless the user explicitly requests another location.
